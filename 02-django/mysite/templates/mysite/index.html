Requests for static files never reach Django

Because STATIC_ROOT is set, Vercel ran collectstatic during the build. It gathered this page's stylesheet from mysite/static/ and the admin's CSS and JavaScript from the installed Django package, and put them on its CDN at /static/. Vercel's router looks for a matching file before it calls the function.

  1. This browser

    Requests a path from this deployment.

  2. Vercel edge

    Receives it at … and looks for a file from the build at that path.

    • A collected file matches

      The CDN answers. The function is not called, so x-vercel-id carries no function region and Django's headers are absent.

    • No file matches

      The Vercel Function in … runs mysite.wsgi.application, and Django's middleware adds x-frame-options: DENY.

The admin login page works without a database

An unstyled Django admin is the usual sign that static files are missing on a serverless host. Here the admin's files come from the same collectstatic run. Showing the login form runs no database query. Submitting it does, because Django has to look up the user and save a session.

Vercel found the app by reading the settings

During the build, Vercel ran manage.py with Django's command runner stubbed out, imported the settings module it names, and read the uppercase settings. Four steps led it to the function's handler.

  1. manage.py

    Sets DJANGO_SETTINGS_MODULE to mysite.settings. Vercel detects Django by finding that name in this file.

  2. mysite/settings.py

    Imported at build time, so it must not reach the network or a database on import.

  3. WSGI_APPLICATION

    Names mysite.wsgi.application. An ASGI_APPLICATION setting would take priority.

  4. mysite/wsgi.py

    Its application object handles every request that doesn't match a static file.

ALLOWED_HOSTS accepts the deployment's own hostnames

With DEBUG off, Django answers 400 Bad Request to any Host header that isn't in ALLOWED_HOSTS. The .vercel.app entry covers default deployment URLs but not a custom domain, so settings.py also appends the hostnames Vercel puts in three system environment variables.
