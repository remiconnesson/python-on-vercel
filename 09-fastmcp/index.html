Connect your own agent in one line

The endpoint is /mcp. Cursor, Claude Code and the FastMCP client negotiate the newer sessionless protocol, 2026-07-28, when they support it; FastMCP 4 serves both protocol versions from the same endpoint. This demo has no authentication, so its tools are read-only.

Stateless means any instance can answer

With stateless_http=True, the server keeps no session between requests, so nothing ties a client to one function instance. That matters because Cursor and Claude Code don't send the cookies sticky sessions would need. Fluid compute still reuses warm instances, which the instance IDs below show.

The path of an MCP request

    Sends POST /mcp with a JSON-RPC request, accepting text/event-stream.

  2. Vercel network

    Received at …, the closest edge location, and routed to the function.

  3. Vercel Function

    FastMCP runs the tool in … and streams notifications and the result back.

A tool call is one function request, so it can run for up to 300 seconds by default. The tools here are read-only and open to anyone; for real tools, add one of FastMCP's authentication options, such as bearer tokens or OAuth, before connecting agents. find_demo searches a snapshot of the Python on Vercel catalog bundled with the deployment.
