The AI SDK for Python calls AI Gateway with no API key and streams what useChat reads

This page is served by a FastAPI app built on ai, the official AI SDK for Python, in public beta. The SDK sends model calls to Vercel AI Gateway, one endpoint for many model providers. On Vercel it signs them with the deployment's OIDC token, an identity token Vercel attaches to each request, so the project stores no key. Every result below comes from this deployment.

The chat route speaks the stream protocol that useChat reads

POST /api/chat takes a message list in the format the useChat hook sends. An ai.Agent with one tool, get_weather, answers it: the model asks for the tool, the function runs it, and the model writes the reply. ai.ui.ai_sdk.to_sse turns each step into a data: line of the AI SDK UI message stream. This page has no AI SDK code; it reads those lines by hand, the way useChat does.

Each send starts a new conversation. When the model uses the tool, one send makes two model calls.

Tokens reach the browser while the model is still writing

GET /api/stream opens ai.stream and yields the text of each TextDelta event as plain text. Python functions on Vercel stream by default, so each piece leaves the function as soon as it is yielded instead of waiting for the full answer.

Every model call is billed to the team's AI Gateway credits. get_weather returns fixed text, so the demo needs no weather service.

        
The ai package is in public beta and its minor releases have included breaking changes, so uv.lock pins the version shown above. In 0.8.0 the chat adapter sends a tool's input as tool-input-delta and no tool-input-available event; useChat handles this, and a hand-written client should not wait for the second one. The finish event carries the source messages the app needs to rebuild history on the next turn.

        
Once a stream has started, its status is already 200, so later failures arrive in the body: an [error] line from /api/stream and an error event from /api/chat. Run locally, the app has no OIDC token unless you set AI_GATEWAY_API_KEY or pull a token with vercel env pull, which lasts 12 hours. Without either, the model routes answer 503.
